## 3. 지표 2 — 하향 재판독 유발 트리거 계수 [판정 입력]

정의(사전등록): pivot 이 직전 활성 판독보다 **하향** 재판독된 뒤, **그 새 pivot 돌파**로 트리거 평가가 발화한 사례 수 + 그중 go_now 도달 수.
- '돌파' = `trigger_gate` 의 close > pivot 경로(`breakout`·`breakout_from_watch`, go_now 가능). `promotion`(close ≥ pivot×0.95, §3.3 go_now 전면 금지)은 돌파가 아니므로 판정 비입력 — descriptive 로 병기.
- 범위 = 하향 행 36 + **내려간 pivot 을 그대로 유지한 후속 행 10**(same/near·Δ≤0·pivot < 옛 pivot; 상향 재판독이나 베이스 변경에서 중단, R1-1). 하향 행만 보면 후속 주에 같은 낮은 pivot 으로 발화한 건이 빠진다.
- different(새 베이스) 하향 5행은 재판독이 아니라 제외(그 아래 돌파 평가 1건, go_now 0 — R1-5 병기).

| 항목 | 값 |
|---|---|
| 하향 재판독 행(same+near) | 36 (same 25) + 유지 후속 행 10 |
| 그 분류들을 prior 로 한 상향 트리거 평가 | 28 |
| └ promotion | 25 (옛 pivot 가격 조건이었다면 미발화 4) |

| &nbsp;&nbsp;09-04 close 22,450 | 옛 pivot 이었다면 어떤 트리거도 미발화(promotion 하한 22,467 에 17.6원 미달), LLM wait |

해석(확정): 하향 재판독이 돌파 발화를 만든 경로가 실전에서 1종목 3회 발생했고, 2차 방어(LLM 정밀 판정 wait)가 매수를 막았다. "구조적 위험 존재·실전 발현 0"(지표 2 = 0) 종결 조건은 **충족되지 않는다**.

## 6. 판정과 권고

**판정(사전 봉인 규칙 적용)**: 지표 2 = 3 > 0 → 보류 대안 개봉 논의 개시. 본 이슈는 여기서 종료, 개봉은 별도 이슈.

**권고안(개봉 이슈의 출발점, 책 근거)** — 책에서 pivot 은 의견이 아니라 구조에서 기계적으로 정해지는 값이다(오닐: 손잡이 고점 + 소폭, 손잡이 없으면 컵 왼쪽 고점, 더블바텀은 가운데 봉우리 / 미너비니: 마지막 수축 구간 고점). 사람이 안 흔들리는 이유는 지난주를 기억해서가 아니라 같은 구조에서 같은 계산이 나오기 때문. 직전 판독 첨부(anchoring)는 #1 결정대로 계속 기각.

1. **방향 한정 래칫(1순위, 작음)**: 같은 베이스(same·near)에서 새 pivot < 직전 활성 pivot 이면 직전 값을 **트리거 기준**으로 유지(저장 판독값은 그대로 두고 소비 측에서 비교), 높으면 새 값. 비교 대상은 "직전에 트리거에 실제 쓰인 pivot"(저장 최신값이 아니라 래칫 적용 후 값 — 유지 후속 행 10 이 보여주듯 저장값 비교만으로는 체인이 끊긴다). 근거 = 같은 베이스에서 pivot 은 내려오지 않으며 내려온 pivot 으로 사는 것은 "베이스 안 매수". 숫자 임계가 없어(방향만) 허용폭 근거 문제를 피한다. 해제 = 직전 행 ignore 또는 different(`_pivot_continuity` 와 동일 의미론). 비용 = 직전 pivot 이 과대 판독이면 매수가 늦어짐(책의 안전한 쪽 실패, extended 가드 기존).
2. **결정론 pivot 유도(구조적, 큼)**: LLM 은 패턴·베이스 경계만 답하고 pivot 은 코드가 저장 주가에서 책 정의대로 계산(#21 의 entry 파라미터 결정론화와 같은 방향). 전제 = 손잡이 구간 등 경계 필드(현재 스키마 미확인, 추정)·프롬프트 변경(governance 4-6)·백테스트 재현성 영향.
3. 베이스 고유 ID 추적: 1·2 가 base_start_date 키로 같은 효과 — 비권장.

기대 효과 상한(1안, 이 표본): 돌파 3 평가 전부와 promotion 4 건(옛 pivot 가격 조건 미발화)을 막았을 것. 돌파 3 중 2 는 promotion 으로 남았을 것(go_now 불가).
