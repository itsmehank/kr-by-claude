## 3. E1 카운터 실측 vs 사전등록 구간 (②)

**주 지표(stage3 prereg §7 분모 정의 — 관측창 LLM 분류 행)**: **2/354 = 0.56%**.

주 단위 분해(주 경계 = KST 월요일 시작):

|---|---|---|
| 2026-07-27 | 63 | 0 |
| 2026-08-03 | 95 | 0 |
| 2026-08-10 | 127 | 1 |
| 2026-08-17 | 47 | 1 |
| 2026-08-24 | 22 | 0 |

해당 2건: 181710(2026-08-15, weekend) · 241710(2026-08-22, weekend) — 둘 다
`classification=watch`, `verdict_original=watch`.

**§7-2 verdict_original 대조**: 두 건 모두 verdict_original == classification —
E1 은 게이트 강등이 아니라 LLM 자가 판정 사유이므로 정합. 하드블록 코드 사실:
`suspected_climax_stage_indeterminate` 는 `trigger_gate.ALLOWED_WATCH_REASONS`
(= {unfavorable_market, marginal_tt, valid_base_awaiting_breakout},
`trigger_gate.py:45-47`) 비포함 → breakout_from_watch 미발화, promotion 경로만
(go_now 금지, `store.py:84-89`). 관측창에서 이 두 건이 promotion 을 실제로 통과
시도했는지의 이벤트 로그 대조는 이 판독 범위 밖(집계 한정).

**사전등록 추정 구간 3.4~20% 대조** — **분모 비호환 명시**: proxy 구간의 분모는
D_climax(reasoning 에 climax 논의가 있는 행)인데 실전 카운터의 주 분모는 전체 LLM
분류 행이라 직접 비교할 수 없다. 보완용 참고 분모(D_climax 동일 패턴, 관측창 LLM
행 reasoning 대상): **88행 → 2/88 = 2.3%**.

- 대조 결과(방향성만): 전체-행 기준 0.56%, D_climax 기준 2.3% — 어느 분모로도
  proxy 하한 3.4% **아래**. 실전 E1 발화가 텍스트 proxy 상한(20%)은 물론 하한보다도
  낮게 관측되고 있다.
- **판정 아님**: stage3 prereg §7-3 이 "실전 밴드는 사전 확정하지 않고 최초 관측치를
  기준선으로 별도 후속 사전등록"이라 봉인했으므로, 본 절의 실측(0.56% / 참고 2.3%)은
  **기준선 기록**이며 합격/불합격 판정이 아니다. proxy 는 백테스트 저장본 텍스트
  판독(상한 추정)이고 실전 카운터는 LLM 자가 신고라 측정 기전 자체가 다르다.

## 4. 판정 (③)

**활성화 판정 = 보류.**

- 근거: 활성화 결정의 핵심 증거인 "실전 발화 건 검수"(백테스트 판독의 B/A/C/D
  분류를 실전 표본으로 재현)가 발화 0건으로 **생성되지 않았다**. 검수 표본 부재로
  **"판정 불능"이지 "불합격"이 아니다** — 발화 0은 게이트 결함·정합 어느 쪽의
  증거도 아니며(§2 참고: 이 표본 규모에서 0건은 통계적으로 이례 아님), 백테스트
  정합률 57.89%(중간 밴드 "규약 재검토 신호")를 갱신할 실전 정보가 없다.
- 따라서 D3 체계(shadow 로그 유지·활성화는 별도 결정)를 그대로 유지하고, 재판독
  트리거를 §5 에 봉인한다.

## 5. 재판독 기준 사전 봉인 (④) [design-judgment]

2축 중 **먼저 도달하는 쪽**에서 재판독을 실행한다(이 문서가 재판독 트리거의
사전등록 역할 — 별도 파일 없음):

- **축1(표본)**: 실전 shadow 발화(=would_force) 누적 **10건** 도달.
  [design-judgment] 근거 — 백테스트 판독은 branch_either 38건 표본 중 would_force
  16건 전수 검수로 패턴 판정(B=15/A=0/C=0/D=1)에 충분했다. 그 판독 규모(16건)의
  과반이면서 B/A/C/D 패턴 분포를 논할 수 있는 최소 규모로 10건을 채택한다.
  강제율(ⓐ) 자체는 분모(LLM 모수)가 발화와 무관하게 누적되므로 재판독 시마다
  상한 5% 대비를 병기한다.
- **축2(시간)**: 발화 0건이 지속되어도 **2027-02-28**(관측 개시 +6개월, 주말 실행
  약 26회분) 도달 시 재판독. [design-judgment] 근거 — 발화 0 의 지속 자체가 판정
  자료가 된다: 백테스트 would_force 비율 0.38% 기준 LLM 모수가 ~2,000행에 이르면
  기대 발화 ~7.6건(P(X=0) < 0.1%)이라, 그 시점의 0건은 "실전 발화율이 백테스트보다
  유의하게 낮다(게이트가 실전 모집단에서 사실상 휴면)"는 판정을 지지한다.
- **E1 관측 지속**: 재판독 시마다 E1 카운터(주 지표 + D_climax 참고 분모)를 병기
  한다. 본 문서 §3 실측이 §7-3 이 예고한 "최초 관측 기준선"이며, E1 판독 밴드의
  후속 사전등록은 다음 재판독 시점의 과제로 이월한다.

## 6. T-D 단독 과발화 검토 조건 승계 (⑤)

mismatch readout(2026-07-21) §5 권고를 **소멸 없이 승계**한다: 활성화 검토 시점에
**T-D 단독 발화(branch_d ∧ ¬branch_b) 분지에 T-C(40주선 턴다운) 코로보레이션을
추가 조건으로 요구하는 안**을 규약 재검토 항목으로 반드시 다룬다. 백테스트에서
would_force 16건 전량이 T-D 단독 발화 + T-C 전건 False(40주선 상승 지속)였고 15/16
건에서 LLM 이 신호를 인지하고도 정당하게 watch 를 유지했다 — 게이트가 LLM 보다
느슨하게 과발화하는 패턴. 이번 관측창은 발화 0건이라 이 패턴의 실전 재현 여부가
**미관측**이므로, 조건은 활성화 전제 검토 항목으로 그대로 유지된다(재판독 축1 도달
시 실전 발화 건의 branch 구성(`inputs`/`observe` 필드 저장됨)으로 첫 실측 대조).
