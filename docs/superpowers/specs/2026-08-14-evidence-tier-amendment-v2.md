## 1. 소급 금지 (본 개정의 한계 — 고정)

- 본 개정은 **채택 시점 이후의 신규 가설·시험에만 적용**된다.
- 이미 종결된 판정(Arm-53 미재현·Arm-54 불채택·F-S2 미재현·Stage 7/8 기각)을
  같은 데이터로 재판정해 "확증"으로 승격하는 것 금지 — 그 가설들의 재도전은
  본 개정 하에서도 "신규 데이터에서의 확증 시험"을 요구한다.

## 2. 증거 2등급

| 등급 | 정의 | 성립 조건 | 용도 |
|---|---|---|---|
| **확증(confirmatory)** | 사전에 잠근 가설·기준을, 그 가설 설계에 쓰이지 않았고 열람 이력이 없는(또는 해당 가설과 무관한 열람뿐인) 데이터로 시험한 결과 | ① 가설·판정 기준이 시험 전 문서로 고정 ② 대상 데이터의 열람 로그에 이 가설 계열의 선행 열람 없음 | production 채택/기각 결정 |
| **탐색(exploratory)** | 그 외 전부 — 열람한 데이터의 재분석, 결과를 본 뒤 만든 가설의 동일 데이터 시험, 사후 분해 | 산출물 파일명 `exploratory_` 접두 + 문서에 "탐색" 표기 | 다음 가설 설계의 재료 (채택 근거 불가) |

- 핵심 원칙: **데이터는 버리지 않는다. 열람할수록 그 데이터의 "확증 능력"만
  해당 가설 계열에 대해 감가된다.** 탐색 용도는 무제한.

- 파일: `data/backtest/LOOK_LOG.md` — 표 형식(날짜 / 데이터 구간·표본 / 목적 /

- 규칙: 백테스트 구간 데이터의 **결과(성과·판정) 산출 시마다 1행** 추가.
  단순 적재·지표 계산(결과 비산출)은 기록 대상 아님.
- 초기 적재: 기존 열람 이력(A 2021~24 다수 / B 백필·분석 / C 2026-08-14 개봉 /
  A+B 관찰 2건)을 소급 기입해 현재 상태를 정직하게 반영.

## 4. 판정 규칙 (신규 가설용 — 기존 §4 관례 승계 + 등급 결합)

- 채택 결정은 **확증 등급 결과**만 근거로 한다. 기준(방향+가드레일 또는 트랙별
  사전등록 기준)은 시험 전 고정 — 기존과 동일.
- 같은 데이터에 대한 반복 확증 시험은 가설 계열당 1회 — 두 번째부터는 자동으로
  탐색 등급(열람 로그가 판정 근거).
- 탐색 결과로부터 만든 새 가설은 반드시 **그 탐색에 쓰이지 않은 데이터**에서
  확증 시험(F-S2 가 밟은 관찰→재현 2단 구조의 일반화).
