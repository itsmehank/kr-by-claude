## 3. P2-2 — 기대값 분해 (탐색 등급), 기존 수치 인용

excess_net 기준, 3표본 일관 구조:

| 표본 | 승률 | 평균이익 | 평균손실 | payoff | Expectancy | 승자/패자 보유(거래일) | 상위10% 총손익 기여 |
|---|---|---|---|---|---|---|---|
| A | 24.1% | +43.2 | −9.2 | 4.68 | +3.386 | 86.5 / 18.0 | +513.2 (총 +182.8) |
| B | 29.0% | +19.5 | −7.3 | 2.69 | +0.522 | 41.1 / 14.4 | +455.9 (총 +48.6) |
| C | 35.1% | +19.0 | −9.1 | 2.09 | +0.755 | 48.2 / 18.9 | +425.2 (총 +73.2) |
| 풀링(244) | 30.3% | +23.4 | −8.4 | 2.79 | +1.248 | 52.4 / 16.9 | +1402.3 (총 +304.6) |

읽기: 낮은 승률(24~35%) × 높은 payoff(2.1~4.7) × 승자 보유 3~5배 × 상위 10%
트레이드가 손익을 지배 — 교과서적 추세추종 손익 구조이며, Expectancy(excess)는
전 표본 양수. 전형적 실패 모드 3분류(승률 붕괴/payoff 역전/손절 미작동) 중
해당 없음.

**규율**: P2-2 는 탐색 등급이다. 여기서 도출되는 어떤 개선 가설(예: 보유기간·
청산 규칙 변형)도 **확인 판정은 미사용 표본(신규 독립 구간)에서만** 가능하다 —
표본 A/B/C 는 이 분해에 이미 열람·소비되어 확증 재사용 불가(LOOK_LOG 규약).

## 4. P2-4 — 상폐 통과 누락 정량화 (신규, 수익률 비산출)

방법: **가격 미소비 경로** — `bt_delisted_indicators.gate_pass IS TRUE ∧ 금요일 ∧
watch 윈도`(build_frame 금요일 조건 동형)를 상폐 종목의 "통과"로 조작화하고,
build_frame(생존 프레임)·FROZEN_SAMPLE 멤버십과 대조. 가격 테이블
(`delisted_adj_prices`·`delisted_daily_prices`) 무접촉, **수익률 일절 비산출**
(멤버십 카운트만). 스크립트: `scripts/issue116_p24_delisted_omission.py`
(SELECT 전용, 2회 실행 byte 동일 확인).

| 표본 | 윈도 | 프레임 | 추첨 풀 | 상폐 통과 종목 | 누락 비율(반사실 풀 대비) | 100추첨 기대 누락 |
|---|---|---|---|---|---|---|
| A | 2021-01-01~2024-12-31 | 1,840 | 1,840 | **125** (금요일 통과 1,810건) | 6.36% | 6.4종목 |
| B | 동일 | 1,840 | 1,726 (−114 기적재 제외) | **125** (동일 윈도) | 6.36% | 6.8종목 |
| C | 2017-07-01~2020-12-31 | 1,650 | 1,650 | **160** (금요일 통과 2,255건) | 8.84% | 8.8종목 |

누락 비율의 분모는 **반사실 풀(프레임 + 상폐 통과)** — 상폐가 없었다면 프레임에
들어왔을 전체 풀 대비 비율이다(예: A 125/(1,840+125)=6.36%). 프레임 단순 대비로는
A·B 6.79%(125/1,840)·C 9.70%(160/1,650).

정합 체크: frame ∩ 상폐 통과 = 0 (3표본 전부 — 생존 필터 정상 작동),
FROZEN_SAMPLE ∩ 상폐 통과 = 0. carve 평가불능(c1~c7·rs_gate 전부 TRUE ∧ c8 NULL)
= **C 1종목(033180, 금요일 5회 2018-03-16~2018-04-13)·A/B 0** (정정 2026-08-25:
초기 프로브는 `gate_pass IS NULL` 전제였으나 producer 는 gate_pass 를 Python bool
로 항상 non-NULL 기록 — 구조적 0 결함. `gate_pass IS FALSE ∧ c8 IS NULL` 로 수리).
bt_delisted_indicators 커버리지 435종목, 2015-06-15~2024-12-30 — 두 윈도 완전 포함.

읽기(보강·비판정): 표본 프레임은 생존 종목 한정(`stocks.delisted_at IS NULL`)이라,
필터를 통과했으나 이후 상폐된 종목이 A·B 윈도에서 125개(반사실 풀(프레임+상폐통과)
대비 6.4%, 프레임 단순 대비 6.8%), C 윈도에서 160개(반사실 풀 대비 8.8%, 프레임
단순 대비 9.7%) 누락됐다. 100종목 추첨 기준 기대 6~9종목 규모의
**생존편향(수익률 상방 편향 방향)** 이 표본 구성에 존재한다. 이 누락분의 수익률
영향 산출은 본 작업 범위 밖(가격 소비 필요 — 승인 소비자 열거 규칙상 보류)이며,
방향성만 기록한다: 기존 "미입증" 판정을 뒤집는 방향이 아니라 **점추정을 더
보수적으로 읽어야 할 방향**이다.

한계: ① RS 축 차이 — c8/rs_gate 는 bt_rs(무편향, 상폐 포함 유니버스) 축으로

소폭 드리프트 가능 — B 추첨 시점 풀 1,730 문서 기록 vs 현재 1,726).

## 5. 해석 지침 갱신

- 승계(기존, #115/#118 시점): "3회 미입증 + 방어 3회 재현 = '해롭지 않음 +
  방어 게이트 작동'까지 지지, **엣지 유무는 유보**."
- 갱신(P2-1 반영): "3회 미입증은 **검정력 부족 구간의 결과 — 엣지 없음의 증거가
  아님**(MDE80 = A 16.3 / B 7.6 / C 5.3%p vs 점추정 +0.5~+3.4%p). 점추정은
  3표본 모두 양수이나 CI 가 0 을 포함하므로 엣지 입증도 아님. 단 P2-4 의 상폐
  누락(6~9%)은 점추정에 상방 편향 가능성을 더한다 — 양수 점추정의 해석은 그만큼
  보수적으로."
- 개선 가설(P2-2 유래)의 확인 판정은 **미사용 표본 필요** — A/B/C 재사용 금지.
