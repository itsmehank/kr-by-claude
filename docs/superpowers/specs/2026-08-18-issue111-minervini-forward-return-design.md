# #111 — 1차 미너비니 필터 forward return 결정론 검증 (설계, 사전등록)

> 상태: 초안 — 사용자 승인 시 LOCKED. 승인 전 실행(수익률 산출) 금지.
> 증거 규율: `2026-08-14-evidence-tier-amendment-v2.md` (확증/탐색 2등급 + LOOK_LOG).
> 이 가설 계열("1차 필터 유효성")은 LOOK_LOG 에 선행 열람 없음 → 본 문서 봉인
> 후 1회 실행 결과는 **확증 등급** 성립.

## 1. 목적

깔때기 1단 — 결정론 스크리너의 `minervini_pass`(트렌드 템플릿 8조건)가 시장
대비 정보 가치를 갖는 신호인지, LLM 없이 전수 데이터로 직접 판정한다.
반복 결론 "수익 미입증"의 원인 후보 중 1차 필터의 자체 유효성은 한 번도 직접
측정된 적 없다(#111 본문). 결과는 #110(확장 백필) 범위·#112(2차 LLM 선별
가치) 판단의 입력.

## 2. 확증 주 판정 (봉인)

### 2.1 이벤트 정의 — 전환일

종목의 `daily_indicators` 시계열(그 종목의 관측행 순서)에서

- 직전 관측행 `minervini_pass = false` **AND** 당일 `true` 인 날 = 전환일 T.
- 직전 행이 없거나(최초 관측) 직전 행 라벨이 NULL 이면 전환 아님.
- 같은 종목의 반복 전환은 전부 포함 — 종목 내 상관은 클러스터 부트스트랩이
  처리한다.

실측 근거(설계 시점, 수익률 미산출): 전환 39,357건 / 2,311종목(2017~2026).
2016년 전환 0건 — w52·sma_200 워밍업이 초기 라벨을 자연 차단하므로 별도
좌측 컷은 두지 않는다.

### 2.2 측정 — 4주 시장대비 초과수익

- 기준가: 전환일 **익일(T+1) `adj_close`** — 당일 지표는 당일 종가 산출물이므로
  당일 진입은 look-ahead. T+1 은 그 종목 시계열의 다음 관측행.
- 종료가: T+1 로부터 그 종목 시계열 기준 **20관측행 뒤** `adj_close`.
- 시장 기준: 같은 두 날짜의 지수 종가 — `stocks.market` 기준 KOSPI→`1001`,
  KOSDAQ→`2001` (`index_daily`).
- **초과수익(%p) = 종목 수익률(%) − 지수 수익률(%)** (단리 차).

### 2.3 결손 처리

- T+1 행이 없거나 T+1 이후 20관측행 미만(데이터 우측 끝·상폐)이면 주 판정
  표본에서 제외하고 **제외 건수를 보고**한다.
- 지수 결측일은 실측 0일(설계 시점 확인) — 발생 시 해당 이벤트 제외+보고.

### 2.4 판정 기준 (3분류 — 기존 수익성 판정 어휘와 동일)

전환 이벤트 초과수익의 종목 클러스터 부트스트랩 **95% CI**
(B=10,000, seed=20260721, percentile — `refinement.cluster_bootstrap_ci` 관례):

| 결과 | 판정 |
|---|---|
| CI 하한 > 0 | **유효** — 필터가 시장 대비 정보를 담음 |
| CI 가 0 포함 | **미입증** |
| CI 상한 < 0 | **역효과** |

점추정치(평균)·중앙값·표본수를 함께 보고한다(실용적 크기 판단은 사후 탐색).

### 2.5 구현 관례

- 부트스트랩은 기존 함수와 **수치적으로 동일한** 종목별 (합, 개수) 사전집계
  구현을 허용한다 — 같은 rng 시퀀스(`random.Random(seed)`, sorted tickers 에서
  `rng.choice`)에서 반복별 평균 = Σ합/Σ개수 로 동일. (39,357건 × B=10,000 의
  리스트 확장 회피.)
- 전 과정 읽기 전용(DB SELECT + JSON 산출). 산출물:
  `data/backtest/issue111_minervini_transition_judge_YYYYMMDD.json`.
- 실행 후 LOOK_LOG 1행 기입(확증). 탐색 부속(§4)은 `exploratory_` 접두 산출물
  + 별도 행.

## 3. 부 관찰 (사전 명시 — 판정에 사용하지 않음)

8주(T+1 후 40관측행)·13주(65관측행) 동일 방법. **horizon 별 독립 제외**(그
horizon 의 행 수 미달 이벤트만 그 horizon 에서 제외) + horizon 별 제외 건수
보고. 지속성 관찰용 — 판정은 4주 단일.

## 4. 탐색 부속 (자유 수행, 채택 근거 불가)

① 통과일 전체 풀링 vs 미통과 비교 ② 조건 개수(c1~c8 합 0~8) 계단별 성과
(단조성) ③ 시장 국면별 분해(`phases`) ④ 모멘텀 교락 관찰(전환 전 수익률 통제)
⑤ **시간 클러스터 강건성**: 전환월 단위 클러스터 부트스트랩으로 §2.4 CI 재계산
— 횡단면 상관(§5)에 대한 민감도 확인. 결과에 따라 항목 추가 가능.

## 5. 한계 (고정 명시 — 결과 해석 시 필수 인용)

1. **생존 편향**: DB 유니버스는 사실상 현재 상장 종목(상폐 보존 12종목, 전부
   2026-06 이후 상폐). 과거 상폐 종목 부재 → 절대 수준 상향 편향 가능. 통과/
   미통과 양군 공통이므로 해석은 상대 비교(신호의 정보 가치) 중심.
2. **이전상장 지수 매핑**: `stocks.market` 은 현재값 — 시장 이전 종목은 과거
   구간도 현재 시장 지수 대비로 계산된다(기존 파이프라인 `INDEX_OF` 관례와
   동일).
3. **횡단면 상관**: 전환이 연도별 편중(2021년 6,965 vs 2022년 1,840) — 같은
   시기 전환들은 공통 충격을 공유하나 종목 클러스터 CI 는 이를 반영하지 않아
   CI 가 실제보다 좁을 수 있다. 시장 대비 초과수익이 일부 상쇄, §4-⑤ 가 민감도
   를 보고, 시간 클러스터로도 "유효" 가 유지되는지는 해석 시 함께 인용한다.
4. **실매매 수익 아님**: 거래비용·유동성·체결 미반영. 본 시험은 "필터가 정보를
   담는가" 만 판정하며, 필터 임계 변경의 근거로는 별도 확증이 필요하다(#111
   본문 규율).
5. **거래정지 스팬**: 종목 관측행 기준 20행은 정지 기간이 끼면 달력상 4주보다
   길 수 있다 — 지수도 같은 두 날짜로 계산하므로 초과수익 정의는 일관.
