## 3. 적재 설계

1. `stocks` 에 부재 종목 INSERT: ticker·name(스냅샷/KIND 확보)·market(스냅샷
   소속)·`delisted_at` = 마지막 관측일 다음 거래일(근사 — KIND 대조로 후속 정밀화),
   `is_common` = 코드 끝자리 0 근사(KIND 대조로 후속 정밀화).
2. `daily_prices` 에 **raw OHLCV 만** 적재(존재 날짜만).
3. **수정주가(adj) 리스크 — 본 설계의 최대 미해결점**: 기존 adj 는 Naver 경로라
   상폐 종목은 조회 불가 개연성. 1차 조치 = raw 적재 + `corporate_actions`(DART)
   기반 조정 계수 산출 가능성 검토(기존 재정규화 로직 재사용). **adj 확보 전에는
   상폐 종목을 지표 계산에 투입하지 않는다**(왜곡 방지) — 투입 시점은 RS 재계산
   설계 문서(§4)에서 결정.
4. 라이브 영향 0: 적재는 과거 구간 전용, 현행 수집 잡·후보 선정 로직 무접촉.

## 4.5 adj 재구성 대조 검증 (전문가 4차 승인 조건 — 1차 측정 완료 2026-08-18)

### 1차 측정 결과 (생존 종목, 저장본 + 소량 KRX ~12요청)

1. **정답 규모**: 생존 종목의 조정 계수 점프(|Δfactor|>0.5%) = **3,037건 / 1,301종목**
   (유니버스 절반). 대형(>30%) 1,301 / 중형(5~30%) 794 / 소형(0.5~5%) 942.
2. **DART 단독 커버리지 부족(확정)**: 점프 ±60일 내 공시 매칭률 — 대형 67.6% /
   중형 82.6% / 소형 48.2%. `corporate_actions` 는 ratio 전부 NULL·분할 이벤트
   미수집(파서 범위 밖) — **DART 단독 재구성은 기각**.
3. **상장주식수 경로 검증 PASS(4/5)**: 최근 대형 점프 5건에서 상장주식수
   변화율이 조정 배율을 정확 재현(5:1→0.2000, 10:1→0.1000). 1건은 복합 이벤트로
   경계 정밀 측정 필요(엣지 처리 대상).

### 개정된 재구성 경로

- **주 경로 = 상장주식수 스냅샷**: 날짜 기준 수집 루프에 `get_market_cap_by_ticker`
  (+2요청/일) 추가 — 상폐+생존 전 종목의 일별 상장주식수 확보. 조정 배율 =
  경계일 주식수 비율(분할·병합·무상·감자 정확). 유상증자 권리락은 주식수+공시로
  근사(소형 밴드 잔차 예상).
- **보조 = DART corporate_actions**: 사유 라벨·경계일 대조·복합 이벤트 분해.

### 대조 검증·허용치 절차 (수집 후 — 적재 확정 게이트)

- 수집 데이터로 **생존 종목 전수** 재구성 → 기존 pykrx adj 대비 오차 분포 보고
  (ticker-day 상대오차 분위수 + 이벤트 경계 누락 수) → **허용치 CC 제안 →
  방법론 세션 합의 후 봉인** → 충족 시에만 상폐 종목 adj 산출·지표 투입. 미충족
  시 상폐 종목 raw 전용 유지(수집 자체는 raw 라 낭비 없음).
- 허용치 프레임(제안 예정 형식): "상대오차 p99 ≤ X% AND 대형 이벤트 경계 누락 0".
