## 3. 적재 설계 — 기존 테이블 무접촉 원칙

**기존 데이터 수정 0·기존 로직 영향 0**을 스키마 수준에서 보장한다:

1. **신규 테이블 2개** (schema.sql 추가 + kr_pipeline·kr_test 양 DB psql 수동 적용
   관례):
   - `delisted_daily_prices` — 상폐 종목 raw OHLCV(ticker, date, open, high, low,
     close, volume, value). **adj 컬럼 없음** — 기존 `daily_prices` 의 adj_close
     NOT NULL 제약과의 충돌을 원천 회피하고, 미검증 수정주가가 기존 소비처
     (지표·csv·payload)로 흘러들 경로를 차단.
   - `share_counts` — 생존+상폐 공용 일별 상장주식수(ticker, date, shares).
2. `stocks` 에 부재 종목 **신규 행 INSERT** (기존 행 수정 없음): ticker·name·
   market·`delisted_at` = 마지막 관측일 다음 날(근사, KIND 로 후속 정밀화)·
   `is_common`(끝자리 0 근사). **delisted_at 이 채워지므로 라이브 경로 전부에서
   자동 제외** — 실측 확인: 수집(ohlcv/modes)·지표(indicators/load)·drift·
   market_context 모두 `delisted_at IS NULL` 필터 사용.
3. 상폐 종목의 adj 산출·`daily_prices` 통합 여부는 §4.5 허용치 통과 후 RS 재계산
   설계 문서에서 결정 — 그 전에는 신규 테이블에만 존재.
4. 거래정지일 0값 행은 raw 그대로 보존(리뷰 M-5) — 0값 처리 규칙(기존
   nullify_halt_adj 관례 상속 여부)은 §4.5 재구성·소비 설계에서 필수로 다룬다.
5. 빈 응답 = 오류로 취급(세션 만료가 빈 DF 로 나타나는 pykrx 특성 — 리뷰 C-1),
   종목당 3회 실패 시 스킵·폴백 목록화(리뷰 I-5). still_listed(스냅샷엔 있으나
   DB에 없는 상장 유지 종목)는 수집 제외 — §5-1 커버리지 분모에서도 제외.

## 4.5 adj 재구성 대조 검증 (전문가 4차 승인 조건 — 1차 측정 완료)

### 1차 측정 결과 (생존 종목, 저장본 + 소량 KRX ~14요청)

1. 정답 규모: 조정 계수 점프 3,037건/1,301종목 (>30% 1,301 / 5~30% 794 /
   0.5~5% 942).
2. **DART 단독 기각**: `corporate_actions` ratio 전부 NULL·분할 미수집, 점프
   ±60일 매칭률 48~83%.
3. **상장주식수 경로 PASS(4/5)**: 주식수 변화율 = 조정 배율 정확 재현(5:1→0.2000,
   10:1→0.1000). 1건은 복합 이벤트 — 경계 정밀 측정으로 처리.

### 재구성 경로

- **주 = `share_counts`**(§3-1, 종목별 수집): 조정 배율 = 경계일 주식수 비율.
  유상증자 권리락은 주식수+공시 근사(소형 밴드 잔차 예상).
- 보조 = DART `corporate_actions`: 사유 라벨·경계 대조·복합 이벤트 분해.

### 허용치 절차 (수집 후 — 적재 확정 게이트)

생존 **전수** 재구성 → pykrx adj 대비 오차 분포(ticker-day 상대오차 분위수 +
이벤트 경계 누락 수) 보고 → 허용치 CC 제안(형식: "상대오차 p99 ≤ X% AND 대형
이벤트 경계 누락 0") → 방법론 세션 합의 후 봉인 → 충족 시에만 상폐 adj 산출.
미충족 시 상폐 종목 raw 전용 유지(수집분 낭비 없음).
