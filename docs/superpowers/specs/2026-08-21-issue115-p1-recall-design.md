**전제(판정문 첫 줄 강제)**: 리콜 합격/불합격 기준은 사전등록되지 않았음 —
본 측정은 **진단**이며 사후 임계 부여 금지. 아래 프레임은 후속 결정의 게이트.

- 유동성 적응(에피소드 anchor 전후 20거래일 ≥10억) 승인 — 생존·상폐 동일 적용.
- **진단 프레임 ①-1 — 플라시보 anchor 기준선** (산출 전 지위 봉인):
  > "본 lift 는 진단 통계이며 합격 임계 없음. 단 **lift CI 가 1 을 포함하면
  > 임계 조정 사이클 개시 전 원인 규명 강제**."
  설계: 창별 동일 기계(같은 4주 개구간 윈도우·같은 무편향 게이트 bool_or),
  연도×시장 매칭 무작위 (종목, anchor) 표본, lift(W) = recall / placebo.
  CI = **ticker 클러스터 부트스트랩**(승자·플라시보 양측 재표집, 1,000회,
  2.5/97.5 분위) [design-judgment]. 표본 = 에피소드당 5 드로우, SEED=20260822.
- ①-2 기회 흐름 절대량 병기: 연도별 포착 승자 건수 + 주말 후보 수 절대값
  (판정 질문 = 흐름 충분성, 리콜 최대화 아님).
- ①-3 미포착 분해(의도된 포기 Stage 1 vs 경계 탈락)는 #118 부속으로 이월 —
  후자만 임계 조정의 정당 입력.
- **② 우선순위**: (a) #118 최우선(구간 붕괴+marginal 공통 병목) (b) #118
  보고서 부속 descriptive = 승자 리드타임 분포 + 미포착 승자 anchor 시점
  조건 프로파일(저장본 계산) (c) **임계 조정 개시 요건 5개 봉인** — 전 충족
  전 개시 불가: ①#115 완료 ②lift 트립와이어 통과 ③경계 탈락 클래스 정량화
  ④전방 데이터(2026-07+) 확인 판정 계획 ⑤승격 기준 사전등록.
- ③ 우측 절단 해석 승인 — #118 시 스냅샷 재산출 1회+일자 각인, 연속 갱신
  없음. **말단 18~24개월 연도별 리콜에 절단 주석 상시 부착.**
- 기록: 게이트 상이 17건 전원 unbiased_only — 12차 트립와이어와 방향 정합,
  무편향 재계산 정상 동작 방증.

  민감도: 1주·13주 descriptive 병행(판정 불입력). ← 결정 요청 ⑤ (봉인)

## 3. 지표 정의

- **승자 리콜** = 통과 승자 에피소드 수 / 전체 승자 에피소드 수 (윈도우 §2).
- **후보 축소율** = 주별 게이트 통과 종목 수 / 당주 거래 유니버스 수 —
  실전·무편향 두 게이트 각각 시계열 + 연도별 요약(현행 실측 ~7.9% 대조).
- 결합 해석 프레임(사전 명시): 리콜 높음+축소율 낮음 = 좋은 필터. 임계
  조정 논의는 두 지표 실측 후 별도 사이클(순서 제약 준수).
