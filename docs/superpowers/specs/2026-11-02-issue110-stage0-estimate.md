## 1. 한 줄 결론

전문가 착수 조건("최대 백필 범위의 기대 트레이드 수 → 도달 MDE80 ≤ 3%p")은 **최대 범위 2019~2024(신규 46,335셀)
에서 MDE 1.64~1.73%p 로 충족 → 기각 사유 없음**. 다만 조각별로는 다르다: 2021 은 표본에서 트레이드 발생률이
전체 평균의 45%(0.018 vs 0.041)라 **2021 단독은 미충족**(3.6~5.1%p). 사용자 선택 **2021+2024 는 기존 트레이드를
합치면 2.74%p(충족), 신규만으로는 3.25%p(미충족)** 인 경계. 2023 을 더하면 둘 다 충족(2.32 / 2.60). 병목은 검정력이
아니라 처리 시간이다(2021+2024 일요일 ≈58회, +2023 ≈81회).

## 3. 도달 MDE (전문가 조건: ≤ 3%p)

- 트레이드당 분산: #116 P2-1 표본별 클러스터 SE 로 σ_i² = n_i·se_i² (A 1,817 / B 690 / C 344 — A 꼬리 두꺼움),
  트레이드 수 가중 풀링 **σ² = 801 (σ ≈ 28.3%p)**. iid 분산 709 → 설계효과 1.13(종목 클러스터). MDE80(n) = 2.80·√(σ²/n).
- **목표 3%p 에 필요한 트레이드 = 699건**(기존 241~244 포함 시 신규 458).
- **트레이드/셀은 연도별로 다르다**(표본 셀 연도 = 분류일, 트레이드는 진입일 연도로 귀속하되 watch 창 종료 뒤
  진입은 창 마지막 연도): 2019 0.072 · 2020 0.062 · 2022 0.053 · 2024 0.053 · 2018 0.050 · 2023 0.042 ·
  **2021 0.018** · 2017 0.020. 풀링 0.041. 2021 은 ignore 가 가장 많은 해이지만 돌파 트레이드는 가장 적게 낳는다.

## 5. 슬라이스 우선순위 (#112 입력 반영)

#112 판독 §7: 선별 가치 재측정의 병목은 **ignore 셀**(목표 ≈2,500~4,100). 2021 이 ignore 를 압도적으로 많이
낳는다(1,119 — 2019~24 의 53%). 그러나 §3 대로 2021 은 **트레이드(수익성 재판정)에는 가장 비효율**이라 두 목적이
갈린다. 2021+2024 는 ignore 1,490 / 트레이드 594 로 절충. 2019~24 전량으로도 기대 ignore 2,124 라 #112 목표 하한에
못 미친다 — #112 재측정은 2017-H2~2018 추가(+182) 또는 목표 완화 필요.

## 6. 전제·한계 (보고서 명시)

1. 트레이드/셀(연도별)과 σ² 801 은 표본 A·B·C(무작위 추첨, 2021 셀 1,740·트레이드 32)의 외삽 — 전 모집단에서 같다는
   가정. 표본 A 의 두꺼운 꼬리가 풀링을 끌어올린다(A 만 쓰면 필요 트레이드 1,584, C 만 쓰면 300).
2. **설계효과 1.13 은 종목 133개에서의 값** — 신규 범위는 종목 ~4,700 으로 클러스터 구조가 달라지며, √n 외삽은
   설계효과가 일정하다는 가정이다.
3. **기간 이질성**(#118 10차): 전환 후 초과수익 2017~24 +0.35 vs 2025~26 −2.46 — 2021 단독은 특정 국면(2020 급등 뒤
   천장)이라 기간 의존성이 크다. 재판정의 일반성을 위해 둘 이상 연도를 권장.
4. 생존 편향 — 상폐 2,709셀(5.5%) 제외. #180 ②-2 후 같은 커밋으로 추가 분류해 합산 분석.
5. 프롬프트 버전 — 신규 분류는 현행 프롬프트. 기존 저장본(2026-06~08 버전 혼재)과 섞으면 이질성 → 시작 커밋 핀 +
   분석 시 신규/기존 층 구분. "기존 포함" MDE 는 참고치.
6. 열람 규율(evidence-tier-v2): 신규 조각을 **미열람**으로 보존하면 #108 재판정의 확증 시험장이 된다. 조각을 보고
   다음 조각 진행을 정하면 선택적 중단(optional stopping)이 섞이므로, **조각 순서와 종료 조건을 착수 전에 고정**한다.
7. 처리량은 4회 관측 — 쿼터 정책에 민감. 첫 2~3회 실측 후 일정 재추정.
8. 트레이드 재구성은 DB 의존(2026-08-18 244건 → 오늘 241건, drift 재정규화) — σ² 는 08-18 권위 수치 유지.
