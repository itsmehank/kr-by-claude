## 3. 도달 MDE (전문가 조건: ≤ 3%p)

- 트레이드당 분산: #116 P2-1 표본별 클러스터 SE 로 σ_i² = n_i·se_i² (A 1,817 / B 690 / C 344 — A 는 꼬리가 두껍다),
  트레이드 수 가중 풀링 **σ² = 801 (σ ≈ 28.3%p)**. MDE80(n) = 2.80·√(σ²/n).
- **목표 3%p 에 필요한 트레이드 = 699건** → 기존 244 를 빼면 신규 455건 = **신규 셀 ≈ 10,900**.

## 5. 슬라이스 우선순위 (#112 입력 반영)

#112 판독 §7: 선별 가치 재측정의 병목은 **ignore 셀**(목표 ≈2,500~4,100). 2021 이 ignore 를 압도적으로 많이
낳는다(1,163 — 전 기간의 55%). 따라서 순서 = **2021 → 2024 → 2023 → 2022 → 2020 → 2019**.
단, 2019~24 전량으로도 기대 ignore 2,128 이라 #112 목표 하한(2,500)에 못 미친다 — #112 재측정은 2017-H2~2018
추가(+182) 또는 목표 완화가 필요하다. 수익성 재판정(#116, MDE)만 보면 2021 조각으로 충분하다.

## 6. 전제·한계 (보고서 명시)

1. 트레이드/셀 0.0417 과 σ² 801 은 표본 A·B·C(무작위 추첨) 외삽 — 전 모집단에서 같다는 가정. 표본 A 의 두꺼운
   꼬리가 풀링을 끌어올린다(A 만 쓰면 필요 트레이드 1,584, C 만 쓰면 300).
2. 2021 단독은 특정 국면(2020 급등 뒤 2021 천장)이라 **기간 의존성**이 크다. MDE 는 충족하지만 재판정의 일반성을
   위해 2021+2024(또는 +2023) 이상을 권장.
3. 생존 편향 — 현재 상폐 종목 제외(2019~24 425셀). #180 ②-2 후 같은 커밋으로 추가 분류해 합산 분석.
4. 프롬프트 버전 — 신규 분류는 현행 프롬프트. 기존 저장본(2026-06~08 버전 혼재)과 섞어 쓰면 이질성이 생긴다.
   시작 시점 커밋을 핀(이슈 본문 "코드 버전 핀")하고, 분석 시 신규/기존을 층으로 구분.
5. 처리량 추정은 4회 관측 — 쿼터 정책 변화에 민감. 첫 2~3회 실측 후 일정 재추정.
6. 열람 규율(evidence-tier-v2): 신규 조각은 **미열람**으로 보존하면 #108 재판정의 확증 시험장이 된다. 백필 중
   진행 모니터링(건수·실패)은 열람이 아니다. 중간 결과(분류 분포·수익률)를 보지 않는다.
