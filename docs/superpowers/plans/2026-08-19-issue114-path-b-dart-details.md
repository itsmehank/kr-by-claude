# #114 경로 B — DART 구조화 공시 기반 v3 재구성 작업 계획

> 전문가 6차 승인(2026-08-19) 이행 계획. 상태: 착수 대기.
> 설계 원문: specs/2026-08-18-issue114-delisted-restore-design.md §4.5 + #114 6차 코멘트.

## 목표

증자·감자·분할류의 **기준일(→권리락일)·비율·발행가**를 DART 구조화 엔드포인트에서
직취해 v3 재구성 → 재측정 → 잔여 건 분류 → 동결 v3에 허용치 봉인.

## Phase 1 — DART 구조화 엔드포인트 검증·클라이언트 확장

- 대상 엔드포인트(주요사항보고서 주요정보 계열, 실명은 소량 실호출로 확정):
  유상증자결정(piicDecsn — `ic_mthn` 증자방식으로 주주배정/3자배정/일반공모 판별),
  무상증자결정(fricDecsn), 유무상증자결정, 감자결정(crDecsn), 주식분할·병합결정.
- `dart_client.py` 에 엔드포인트별 fetch 함수 추가(기존 페이싱·재시도 관례 승계).
- 신규 테이블 `corp_action_details`(ticker, rcept_no, action_type, record_date
  기준일, ratio, issue_price, method 배정방식, disclosed_at) — schema.sql + 양 DB.
- 소량 검증: 검증 범위 종목 3~5개의 알려진 이벤트(v2 매칭분)와 대조.

## Phase 2 — 백필 (검증 범위 1,443 + 상폐 435)

- 티커→corp_code 매핑은 기존 corp_code_sync 재사용(상폐 종목 corp_code 존재
  여부 확인 필요 — DART 는 상폐 후에도 corp_code 유지 추정, Phase 1 에서 검증).
- DART 쿼터(일 2만) 내 배치 — KRX 무관.

## Phase 3 — v3 재구성 + 재측정

- v3 = v2 + corp_action_details: 소형 조정의 시점 = 기준일−1영업일(권리락),
  배율 = 유상(TERP 공식: 발행가 반영)·무상(1/(1+비율))·감자(비율) 직접 계산.
  3자배정·일반공모(권리락 없음 유형) = 이벤트 제외 → FP 차단.
- 기존 오차 리포트 러너 재사용(--v3) → 오차 분포.

## Phase 4 — 잔여 건 분류 (전문가 6차 ③)

- 대형 41건: DART 행위 유형 전수 분류 → (a) v3 반영 / (b) 품질 플래그 층화 /
  (c) 데이터 결함 별도 등록.
- FP 47건: DART 원공시 심판(5차 ②) — pykrx 누락은 DB 결함 등록 + FP 제외.
- 소형 잔존분: 품질 플래그 층화.

## Phase 5 — 커버리지 표 + 허용치 봉인 (전문가 6차 ①②)

- 기업행위 커버리지 표: {유상증자(주주배정/일반공모), 무상증자, 유상·무상감자,
  액면분할/병합, 합병·분할, 주식배당} × {v2 / 경로B / 미처리}.
- 허용치 제안(41·47 분류 반영 후 분포 기준) → 방법론 세션 합의 → **동결 v3 에
  봉인 + 이후 파이프라인 수정 시 재검증 자동 발동 조항** 명기.

## 규율

- DART 호출만(KRX 0). 기존 데이터 무수정 원칙 유지(신규 테이블 + 신규 행만).
- 코드 변경은 리뷰 후 머지(레포 관례), 상폐 종목 지표 투입 금지는 허용치 통과까지.
